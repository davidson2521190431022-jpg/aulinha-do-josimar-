\## 📌 Sobre o projeto



Este projeto é um sistema \*\*CRUD desenvolvido em PHP\*\*, criado com o objetivo de praticar e demonstrar operações de gerenciamento de dados utilizando PHP e MySQL.



CRUD significa:



\- 🟢 \*\*C\*\*reate — Criar

\- 🔵 \*\*R\*\*ead — Ler

\- 🟡 \*\*U\*\*pdate — Atualizar

\- 🔴 \*\*D\*\*elete — Excluir



O sistema permite cadastrar, visualizar, editar e excluir registros de forma simples e organizada.



\---



\## ✨ Funcionalidades



\- ✅ Cadastro de novos registros

\- 📋 Listagem dos registros

\- ✏️ Edição de registros

\- 🗑️ Exclusão de registros

\- 🔎 Visualização dos dados

\- 💾 Integração com banco de dados MySQL

\- 🎨 Interface simples e responsiva
